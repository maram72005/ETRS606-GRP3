# TP3 - Cloud Connectivity

## Objective

This folder contains the work carried out for TP3 on cloud connectivity, sensor data collection, and weather classification using cloud-based tools.

## Main Topics

- Sending sensor data to the cloud
- ThingSpeak channel configuration
- Data visualization on a web dashboard
- MATLAB data processing
- Statistical analysis of collected measurements
- Cloud alerts and remote commands
- Weather classification with Meteostat data
- AI model training with Python and TensorFlow

## Cloud Platform

- ThingSpeak
- MATLAB

## Data Collected

- temperature
- humidity
- pressure

## Main Tasks

### Part 1 - Data Collection in ThingSpeak
- send raw sensor data to a ThingSpeak channel
- visualize measurements on the platform
- process data using MATLAB scripts
- compute averages over a selected time window
- trigger cloud actions such as alerts and remote control

### Part 2 - AI Training for MeteoStat
- build a weather classification model in Python
- use Meteostat data for training
- define weather classes
- study the trade-off between:
  - number of classes
  - model size
  - accuracy
  - training choices
