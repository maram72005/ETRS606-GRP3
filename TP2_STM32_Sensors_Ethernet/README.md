# TP2 - STM32 Sensor Interface and Ethernet Communication

## Objective

This folder contains the work carried out for TP2 on STM32 embedded programming, sensor interfacing, and Ethernet communication.

## Main Topics

- LED blink and running light sequence
- Serial console logging
- I2C sensor interfacing
- Integration of ST sensor drivers
- Sensor data acquisition
- FreeRTOS integration
- LwIP configuration
- Ethernet communication with DHCP and ICMP

## Hardware

- NUCLEO-N657X0
- X-NUCLEO-IKS01A3

## Parts

### Part 1 - LED Blink
Basic LED control on STM32:
- red LED
- green LED
- blue LED
- 3-second running light sequence
- console logs for system state monitoring

### Part 2 - Sensor Interface
Sensor communication through I2C:
- integration of ST drivers
- implementation of low-level read/write functions
- acquisition of sensor values
- display of measurements on the serial console

### Part 3 - Ethernet Communication
Network setup on STM32:
- FreeRTOS integration
- LwIP stack configuration
- DHCP and ICMP support
- ping test through Ethernet
- system activity logs on console
