# TP1 - MNIST Classification with MLP

## Objective

This folder contains the work carried out for TP1 on handwritten digit classification using the MNIST dataset.

## Main Topics

- Dense neural network for image classification
- Flattened 28x28 grayscale input images
- Multi-class classification from 0 to 9
- Comparison of activation functions
- Comparison of optimizers
- Comparison of loss functions
- Evaluation of model accuracy and complexity

## Dataset

- MNIST handwritten digit dataset
- Input size: 28 x 28 pixels
- Flattened input vector: 784 values
- Output classes: 10 digits

## Experiments

### Activation Functions
- softmax
- ReLU
- tanh
- sigmoid

### Optimizers
- SGD
- Adam
- RMSprop
- Adagrad

### Loss Functions
- categorical_crossentropy
- sparse_categorical_crossentropy

## Evaluation Criteria

- accuracy
- number of epochs
- number of parameters
- memory cost
- overall trade-off between performance and model size
